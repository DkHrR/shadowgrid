# ShadowGrid

A privacy-preserving grid game built with Midnight Compact.

## MVP UI

1. Download the latest \uild-artifacts\ ZIP from the [GitHub Actions runs](https://github.com/DkHrR/shadowgrid/actions).
2. Extract the \dist\ folder into the root of this repository.
3. Run \
pm install\
4. Run \
pm run dev\
5. Open your browser to \http://localhost:5173\ and connect your Midnight Lace wallet (Testnet).
